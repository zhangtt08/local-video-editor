# UI 设计演示（静态稿）

三个纯 HTML 页面，无构建、无外部依赖（系统字体 + 内联 SVG），双击即可打开，或 `python -m http.server 8901` 后访问 `http://127.0.0.1:8901/index.html`。

| 页面 | 对应任务 D 范围 | 演示交互 |
|---|---|---|
| index.html | 项目列表、能力清单（capabilities 如实显示）、新建项目 | 能力标签、新建对话框 |
| editor.html | 素材面板、预览占位、检查器、时间线、命令预演/提交 | 选中片段、标尺拖播放头、分割/修剪/移除→命令、提交后幽灵片段转正 + revision+1、缩放、工具切换（V/C） |
| history.html | 历史审计、恢复 | 两段确认恢复 → 生成新版本，版本号只进不退 |

## 设计约定

- 白灰亮色（`#f6f6f8` 底 / `#ffffff` 面板 / `#e6e6ea` 发丝线），信号蓝 `#2b59d8` 只用于播放头、选中态、主按钮。
- 所有时间、tick、revision、request_id 一律等宽字体（Cascadia/Consolas）——时间在本产品里是数据。
- 签名元素：时间线上的**幽灵片段**（虚线 + 提案标签）= Agent dry-run 候选，提交后转正。
- 未实现的能力如实显示不可用（预览占位标注 `capabilities.preview = false`），不用演示帧冒充。
- 编辑器底部常显时间基 `70,560,000 tick/s · 1 帧 = 2,352,000 tick`。

## 已知简化

- 片段暂不支持鼠标拖拽移动（正式版走 React + 命令预演）；波形为 CSS/SVG 生成纹理，非真实解码。
- 预览监视器为占位；导出按钮未放置（render=false，等任务 B）。
- 转正式实现时按任务 D：界面只走 HTTP 批命令，409 冲突时刷新重试，Token 不进前端 bundle。
